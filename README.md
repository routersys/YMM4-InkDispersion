# 墨拡散 for YMM4

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](#)
[![.NET](https://img.shields.io/badge/.NET-10.0-purple.svg)](#)
[![Release](https://img.shields.io/github/v/release/routersys/YMM4-InkDispersion.svg)](https://github.com/routersys/YMM4-InkDispersion/releases)

---

YukkuriMovieMaker4（YMM4）上で動作する、素材の形に置いた墨が紙へにじみ広がる様子を描く映像エフェクトプラグインです。
素材の不透明な部分に墨を置き、紙の中を水が浸透していく流れを計算して、水に運ばれた墨が定着した形を描きます。
「拡散度」を時間で変えると、文字や図形が紙へにじんでいく動きになります。

## 概要

本プラグインは YMM4 の映像エフェクトとして動作します。エフェクトの一覧の「装飾」と「アニメーション」に「墨拡散」として表示されます。現在のフレームの不透明度から素材の形を求め、素材を覆う格子のセルに墨を含んだ水を置き、水が紙の中を広がる様子を格子ボルツマン法で計算します。格子ボルツマン法は、セルからセルへ移る水の量を短い時間の刻みごとに求める計算法です。計算の組み立ては、Chu と Tai の論文「MoXi: Real-Time Ink Dispersion in Absorbent Paper」（SIGGRAPH 2005）に沿っています。

計算に使うのは現在のフレームだけです。前後のフレーム、外部の画像、学習済みのモデルは使いません。乱数は「シード」と位置だけから決めます。時刻や描画の回数は使わないため、同じフレームは何度描いても同じ結果になります。

浸透の計算は Direct3D 12 の計算シェーダーで行います。YMM4 が描画に使う Direct3D 11 との間は、共有テクスチャと共有フェンスで受け渡します。設定はアイテムのエフェクトの項目としてプロジェクトに保存します。プラグイン自体の設定ファイルはありません。

画面の表示は日本語のほか、英語、簡体字と繁体字の中国語、韓国語、スペイン語、アラビア語、インドネシア語に対応します。

## インストール方法

1. [Releases](https://github.com/routersys/YMM4-InkDispersion/releases/latest) ページから最新のプラグインファイル（`.ymme`）をダウンロードしてください。
2. YMM4 が起動していないことを確認し、ダウンロードしたファイルを実行してインストールします。
3. YMM4 を起動し、アイテムの映像エフェクトから「装飾」か「アニメーション」の「墨拡散」を追加します。
4. 既定の設定では、素材の縁から素材の長辺の 25% の距離まで墨がにじみます。「到達距離」と「水量」で広がりを、「拡散度」で進み具合を調整します。

## 主な機能

### 1. 浸透の計算

素材のうち不透明な部分を、浸透を計算する格子のセルに写します。各セルは、その範囲に含まれる画素の不透明度の平均に応じた量の水を、墨を溶かした状態で表面に持ちます。その量は「水量」で増減します。

水は 1 ステップに隣のセルへ 1 セル分だけ進みます。各セルには水の通しにくさを表す阻害係数があり、隣り合うセルの間の通しにくさは、両方のセルの阻害係数を平均した値です。通れなかった分の水は元のセルへ跳ね返ります。阻害係数は「繊維」「にじみ止め」「粘度」と、そのセルに定着した墨の量から決まります。

水の進む先端を前線と呼びます。乾いたセルは、隣のセルの水が一定の量に達するまで水を受け入れにくく、前線はそこで足止めされます。足止めの起きやすさは場所ごとに違うため、前線は一様に進まず、縁が荒れます。

墨は水に運ばれます。水が初めて届いたセルでは、流れ込んだ水の量に応じて上流のセルの墨を受け取ります。すでに濡れているセルでは、流れの向きと速さから 1 ステップ前にどこの墨がここへ来たかを求め、その墨を受け取ります。水が減る場所では墨がその場に定着し、定着した墨は以後の流れを妨げます。

### 2. 拡散度によるにじみの進み

各セルは、墨が最初に定着したステップの番号を覚えています。「拡散度」は、何ステップ目までのにじみを描くかを決めます。0% では何も描かず、100% では最後のステップまで描きます。描く範囲の境目は 1 ステップ分の幅で滑らかにつなぎます。番号の順に描くため、「拡散度」を時間で上げると、素材から外へ墨がにじみ広がる動きになります。

### 3. 紙と墨の性質

「繊維」は、紙の繊維むらの強さです。繊維むらは「シード」から作る模様で、模様の濃い場所ほど水が通りにくく、墨も流れから遅れます。「繊維」を上げるほど流れが妨げられて枝分かれし、下げるほど滑らかに広がります。

「にじみ止め」は、礬水による浸透の妨げです。礬水は、明礬と膠を溶いて紙に引き、にじみを抑える液です。高くするほど阻害係数が上がり、前線の足止めが解ける水の量も増えるため、縁が荒れて広がりが抑えられます。

「粘度」は、膠による墨の粘りです。高くするほど水の流れが遅くなり、阻害係数が上がり、墨が定着しやすくなります。

「シード」は、紙の模様を決める値です。繊維むら、にじみ止めのむら、前線の足止めのむら、描画のときの紙目がこの値から決まります。同じ設定のアイテムを複数置くときに、シードを変えると別々の形になります。

### 4. にじみの広がり

「水量」は、素材に置く水の量です。置いた水は、セルに入る量の上限まで、1 ステップごとに少しずつ紙へ移ります。多いほど供給が長く続き、水が遠くまで届きます。

「乾燥」は、水が蒸発する速さです。1 ステップごとに水が減り、減った分に応じて墨が定着します。高くするほど早くにじみが止まり、水を失う縁で墨が濃くなります。

「到達距離」は、墨が届く距離の上限です。素材の長辺に対する割合で指定し、素材の縁からこの距離より遠いセルには水を通しません。長くするほど、水を通すセルの数と繰り返しの回数が増え、計算に時間がかかります。

### 5. 墨の描画

各セルは、定着した墨の量とともに、最も濡れたときの水の量を覚えています。描画では、この 2 つから画素ごとに墨の不透明度を決めます。

「濃度」は、同じ量の墨をどれだけ濃く描くかです。「かすれ」は、紙目によるかすれと縁の荒れの強さです。紙目は、紙の表面の細かい凹凸です。「かすれ」を高くするほど、水が少なかった場所の墨を紙目に沿って削り、墨の境界を荒らします。「墨色」は描く墨の色で、不透明度は使いません。

描いた墨は「強さ」の分だけ元の映像の上に重ねます。0% にすると映像をそのまま通します。

### 6. 計算領域と品質

計算領域は、素材の範囲を「到達距離」と 64px の余白の分だけ四方へ広げた大きさです。計算領域の長辺が 8192px に収まるように「到達距離」を縮めます。到達距離は 1px までしか縮めません。

「品質」は、計算領域を覆う格子の細かさと、繰り返しの上限を決めます。

| 品質 | 格子の解像度 | 繰り返しの上限 |
|---|---|---|
| 標準 | 160 | 720 回 |
| 高品質 | 224 | 1080 回 |
| 最高品質 | 288 | 1440 回 |

格子の解像度は、計算領域の長辺をいくつのセルに分けるかの数です。1 セルの大きさは、長辺をこの数で割った長さになります。短辺のセルの数は縦横比に合わせて決まります。繰り返しの回数は、「到達距離」をセルの数に直した値を 10 倍して 128 を足した回数です。ただし 192 回を下回らず、品質の上限を超えません。

描画するのは、墨が存在する最小の矩形だけです。この矩形が素材の外へはみ出す分だけ、エフェクトの出力範囲を広げます。

## パラメータ一覧

| 項目 | 既定値 | 内容 |
|---|---|---|
| 強さ | 100% | 墨を元の映像に重ねる割合です。0% から 100% までで、0% にすると映像をそのまま通します。 |
| 拡散度 | 100% | 描くにじみの範囲です。0% から 100% までで、0% にすると何も描きません。 |
| 品質 | 高品質 | 格子の細かさと繰り返しの上限です。「標準」「高品質」「最高品質」から選びます。 |
| 水量 | 60% | 素材に置く水の量です。0% から 100% までです。 |
| 到達距離 | 25% | 墨が届く距離の上限で、素材の長辺に対する割合です。スライダーでは 5% から 100% まで、直接入力では 1% から 400% までです。 |
| 繊維 | 50% | 紙の繊維むらの強さです。0% から 100% までです。 |
| にじみ止め | 30% | 礬水による浸透の妨げです。0% から 100% までです。 |
| 粘度 | 30% | 膠による墨の粘りです。0% から 100% までです。 |
| 乾燥 | 40% | 水が蒸発する速さです。0% から 100% までです。 |
| シード | 0 | 紙の模様とにじみの形を決める値です。0 以上の整数で、スライダーでは 10000 までです。 |
| 濃度 | 80% | 墨の濃さです。0% から 100% までです。 |
| かすれ | 40% | 紙目によるかすれと縁の荒れの強さです。0% から 100% までです。 |
| 墨色 | #1E1A18 | 描く墨の色です。不透明度は使いません。 |

「強さ」「拡散度」「品質」は「基本」、「水量」から「シード」までは「浸透」、「濃度」「かすれ」「墨色」は「描画」のグループにあります。「品質」「シード」「墨色」はアニメーションできません。ほかの 10 項目は、YMM4 のアニメーションの設定で時間に沿って変えられます。

## 制限事項

- 墨を置く場所の判定には、現在のフレームの不透明度だけを使います。色と明るさは判定に影響しません。
- 素材の長辺が 8160px を超えるときは、計算領域の余白を取れないため、映像をそのまま通します。
- 「品質」が高いほど格子が細かくなり、計算の量と GPU のメモリの使用量が増えます。「到達距離」が長いほど繰り返しの回数が増えます。
- 墨は素材の外側にも描くため、出力範囲は素材の範囲より広がります。
- Direct3D 12 のデバイスか、YMM4 の Direct3D 11 との共有テクスチャや共有フェンスを作れないときは、映像をそのまま通します。
- AviUtl の exo ファイルへの書き出しには対応していません。

## 注意事項

- 処理の重さ: 浸透の結果は、素材の形と、「水量」から「シード」までの浸透の設定と、「品質」が変わらない限り使い回します。「強さ」「拡散度」「濃度」「かすれ」「墨色」だけを変えても計算し直しません。形が変わり続けるアイテムでは毎フレーム計算し直すため、重いときは「品質」を「標準」にするか、「到達距離」を短くしてください。
- 更新の確認: アイテムに墨拡散を追加するか、墨拡散を含むプロジェクトを開いたときに、YMM4 の起動ごとに一度だけ GitHub のリリースを確認し、新しいものがあればメッセージで知らせます。プレリリースは対象に含めません。
- 不具合の自動送信: 想定していない例外が起きたときは、その内容を開発者へ自動で送信します。内容は「不具合の報告」に書いています。
- 本プラグインを使用する前に、YMM4 プロジェクトファイルのバックアップを作成することを推奨します。

## 不具合の報告

本プラグインは、想定していない例外が起きたときに、その内容を開発者へ自動で送信します。同意は求めず、常に送信します。

送信する情報は次のとおりです。

| 種類 | 内容 |
|---|---|
| 例外 | 型の完全名、メッセージ、スタックトレース |
| 発生位置 | モジュール名、関数名、ファイル名、行番号 |
| プラグイン | アセンブリ名、バージョン |
| 実行環境 | OS の名前とバージョン、.NET のバージョン、CPU のアーキテクチャ、論理プロセッサ数 |
| 識別子 | YMM4 の起動ごとに決まるセッション識別子、報告ごとの識別子 |

メッセージとファイル名は、送信の前に置き換えを通します。置き換えるのは、Windows のユーザー名、ユーザーフォルダー、AppData のパス、マシン名、ドメイン名、メールアドレス、IPv4 アドレスです。送信元の IP アドレスは受信側へ渡す手前で取り除いています。

映像の中身とプロジェクトの内容は送信しません。継続して個人を追跡する識別子も持ちません。セッション識別子は YMM4 を起動し直すと別の値になります。

送信するのは想定していない例外だけです。YMM4 が本プラグインのエフェクトを作るとき、フレームごとに更新するとき、入力をつなぎ直すとき、破棄するときと、Direct2D がシェーダーの定数を書き込むときに起きた例外を報告し、その後は YMM4 へそのまま渡します。画面の操作やバックグラウンドの処理で未処理になった例外も報告しますが、本プラグインのコードが関わる例外に限ります。本プラグインの外で起きた例外は送信しません。

次の失敗は送信しません。

| 種類 | 例 |
|---|---|
| 効果をかけないだけで済ませるもの | Direct3D 12 のデバイスを作れない、YMM4 の Direct3D 11 との共有テクスチャや共有フェンスを作れない、計算領域の余白を取れないときに、映像をそのまま通したとき |
| 更新の確認の通信の失敗 | GitHub へ接続できない |

送信できなかった報告は YMM4 のユーザーフォルダーへ退避し、次回の起動時に送り直します。送信も再送も非同期に行うため、起動と描画が遅くなることはありません。

実装は [YMM4-Telemetry](https://github.com/routersys/YMM4-Telemetry) をサブモジュールとして取り込んでいます。
